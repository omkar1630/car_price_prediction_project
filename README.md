# 🚗 Car Price Prediction System Using Decision Tree Regression

A Machine Learning web application that predicts the estimated price of a car based on various vehicle specifications such as make, model, year, engine size, mileage, fuel type, and transmission.

## 🌐 Live Demo

🔗 https://car-price-prediction-project-szuk.onrender.com/

---

## 📌 Features

- Predicts car prices instantly
- User-friendly and responsive interface
- Attractive modern UI
- Built using Flask and Scikit-Learn
- Deployed on Render
- Decision Tree Regression model

---

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-Learn
- Pandas
- NumPy
- HTML
- CSS
- Gunicorn
- Render

---

## 📊 Input Features

The model uses the following features:

- Make
- Model
- Year
- Engine Size
- Mileage
- Fuel Type
- Transmission
